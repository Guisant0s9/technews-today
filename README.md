# 📱 TechNews Today

Portal de notícias sobre tecnologia desenvolvido em **HTML5** e **CSS3**, com destaque para novidades do mundo tech, conteúdo em vídeo e formulário de newsletter.

## ✨ Funcionalidades

- **Cabeçalho fixo durante a rolagem:** utiliza `position: sticky`.
- **Efeito de vidro fosco:** aplicado ao cabeçalho com `backdrop-filter`.
- **Título com gradiente:** cores em degradê no nome do portal.
- **Notícia em destaque:** conteúdo sobre o impacto da inteligência artificial no desenvolvimento de software.
- **Seção de vídeo:** vídeo incorporado do YouTube.
- **Newsletter:** formulário com campos de e-mail, área de interesse e confirmação dos termos.
- **Layout responsivo:** usa CSS Grid e uma media query para adaptar a disposição do conteúdo em telas maiores.

## 🛠️ Tecnologias utilizadas

- HTML5
- CSS3 (CSS Grid, gradientes, `backdrop-filter`, transições e media queries)

## 📁 Arquivos do projeto

- `10desafio.html` — estrutura e conteúdo da página.
- `10adesafio.css` — estilos visuais da página.

> **Importante:** o HTML referencia a folha de estilos como `10adesafio.css`. Mantenha esse nome igual ao arquivo CSS no repositório ou atualize o caminho no HTML para corresponder ao nome escolhido.

## 🚀 Como executar

1. Baixe ou clone este repositório.
2. Mantenha o arquivo HTML e o CSS na mesma pasta.
3. Abra `10desafio.html` em um navegador.
